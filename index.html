WORKFLOW

How Deadlock Detection Works

The system uses a Resource Allocation Graph to model process-resource relationships, then derives a Wait-For Graph and runs DFS cycle detection.

1

Build the Resource Allocation Graph

Model processes and resources as nodes. Add request and assignment edges between them.

2

Derive the Wait-For Graph

Collapse resources: if P1→R→P2, add edge P1→P2 in the simplified wait-for graph.

3

Run DFS Cycle Detection

Use recursion stack tracking in DFS. A back-edge reveals a cycle = deadlock.

4

Report & Recover

Highlight deadlocked processes. Apply recovery: process termination or resource preemption.
