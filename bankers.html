💡 How Banker's Algorithms Work (Safety & Resource-Request)

1. Safety Algorithm:

• Calculates Need[i][j] = Max[i][j] - Alloc[i][j].
• Sets Work = Available and searches for unfinished $P_i$ where Need[i] ≤ Work.
• When $P_i$ completes, releases resources: Work = Work + Alloc[i].
• If all processes finish, the system is in a safe state with a safe execution sequence.

2. Resource-Request Algorithm:

• Step 1: If Request ≤ Need[i], proceed; otherwise raise error (exceeded maximum claim).
• Step 2: If Request ≤ Available, proceed; otherwise $P_i$ must wait.
• Step 3: Pretend to allocate (Avail -= Req, Alloc[i] += Req, Need[i] -= Req) and test safety.
• If safe: grant request immediately. If unsafe: $P_i$ must wait and previous state is restored.
